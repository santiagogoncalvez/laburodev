# laburoDev

Bolsa de trabajos para developers. Buscador de empleos con filtros por nivel, modalidad y tecnologías, incluyendo resúmenes automáticos mediante Inteligencia Artificial (Gemini).

## Tech Stack
- **Frontend**: React 19, Vite, Zustand, React Router, Streamdown.
- **Backend**: Express 5, Zod, Turso (SQLite en la nube).
- **IA**: Vercel AI SDK + Google Gemini.

## Estructura
- `/frontend`: Aplicación web.
- `/backend`: API REST con persistencia en Turso.
